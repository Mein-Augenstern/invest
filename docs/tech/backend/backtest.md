# 回测口径与首跑结论（2026-09-12）

## 引擎口径（invest backtest）

- **价格序列**：中证红利全收益指数 **H00922**（分红再投资计入收益；当前 12,095 vs 价格指数 5,580，
  13 年分红贡献近乎翻倍——用价格指数回测红利策略会系统性低估）
- **执行节奏**：月度重放，每月首个交易日执行（贴近"月初缴存"）；资金流默认每月 1,000
- **信号**：估值增强用 as-of 滚动 PE 分位（5 年窗，与规则书§1 同源 zones）；
  股债利差用 E/P−10Y 国债（FED 口径）
- **防前视**：引擎裁剪截至当日数据递给策略（结构性保证），单测含"篡改未来不改变过去信号"
- **费用**：申购费 0（Y 份额）；跟踪损耗默认 0（可用 `--drag 0.005` 保守模拟联接基金）
- **已知局限**：指数历史成分变迁 → 幸存者偏差（结论偏乐观，看相对排序比绝对数字可靠）；
  未建模赎回费/税

### 新增口径（B5/B6）

- **股息率推算**：滚动一年 股息率 ≈ TR/价格指数同期涨幅之差（分红再投资贡献）。
  交叉验证：推算最新 4.35% vs 中证官网"股息率1" 4.16%（合理偏差源于窗口/加权细节）。
  序列区间 2.2%~6.4%，具备择时区分度（对比 E/P 的结构性恒高）。
- **年线择时**：250日均线乖离分档（<0 加倍 / 0~30% 正常 / 30~50% 减半 / >50% 停投）。
  当前价与均线统一用价格指数（000922）——曾误用 TR 点位比价格均线致虚假最优，已修复并留档。

### 六策略阅读

- 股息率利差最"挑剔"：只在利差 ≥1pct 时投（94笔/160月），XIRR 10.40%——贵的时候真的不买
- 年线择时浮亏最小（-4.8%）：过热段（乖离>30%）自动减停，2015/2018 顶部的伤害被削掉大半
- E/P 口径确认无区分度（红利结构性"恒便宜"），保留作教育案例并已在页面上注明

### 结论与发现

1. **估值增强定投有效**：对比无脑定投 XIRR +0.87pct/年、倍数 1.96→2.11，且账户浮亏不变
   （多买的 33 个月都发生在便宜区间，停投的月份偏贵）——**规则书§1 的分区参数在红利指数上
   获得历史支持**（仍带幸存者偏差 caveat）。
2. **一次性赢在单边长期向上**：XIRR 10.80% 略高，但代价是全程承受指数 -45.7% 的 2015 级回撤
   （账户浮亏 -14.4% 是"相对成本"，高点回撤的体感远大于此）。对锁定缴存节奏的养老金账户，
   一次性不可执行，参考意义限于"早投入的价值"。
3. **股债利差(E/P口径)在红利指数上退化**：红利 PE 常年 8-9 → E/P≈11-12%，减去 2.7-4% 的
   国债后利差几乎恒 ≥6pct → 策略退化为"永久加倍定投"（总投入 31.5 万≈双倍），无择时区分度。
   **修正方向**：红利指数的利差锚应改用**股息率−10Y**（股息率 4-6% 波动有意义）；
   长历史股息率序列可由 TR/价格指数的增速差推算——列为 B5 任务。
