# 项目章程（v1.0 · 2026-09-05）

## 一、使命

为单一用户（我）构建**个人投研与决策支持平台**，长期运行。覆盖基金/股票/债券等品类，
不同品类采用不同策略引擎，统一账本、统一风险视角。

## 二、三个层次的价值

1. **记清楚**：账本（流水 / 成本 / 资金加权收益率 XIRR），每月与券商 App 对账单核对。
2. **看明白**：估值（指数 PE 历史分位、股息率）、风险（回撤、相关性）。
3. **有纪律**：策略规则化，输出建议信号。所有信号是**纪律工具**，不是收益保证。

## 三、边界与红线

| # | 红线 | 原因 |
|---|------|------|
| 1 | 不接券商/银行自动下单 | 程序化交易有监管要求；个人接口门槛高；本平台定位是决策支持 |
| 2 | 不对外提供服务、不商用 | 个人使用，避免合规问题 |
| 3 | 真实持仓与流水不出本机/局域网 | 敏感数据；仓库可能公开 |
| 4 | LLM 不做涨跌预测 | 只做信息压缩、逻辑推理、报告生成；预测不可靠且有害于纪律 |

### v1.1 边界修订（2026-10-18 · star 平台集成）

接入 star 平台**家庭内网基础设施**（登录/网关/鉴权），不改变红线 2/3 的实质：

- **形态**：invest 以独立微服务（Python）挂 star 网关（`/api/invest/**`），登录复用
  star member 服务（wx-login → 统一 JWT，HS256 共享密钥纵深防御）。
- **边界解释**：star 平台当前部署形态为家庭内网（本机 compose / 局域网），"不出本机"
  修订为"不出本机/家庭局域网"。
- **数据可见性**：invest 账本当前为单用户设计，任何持有有效 star 登录态的家庭成员
  均可读取（家庭内部透明）；不做 member 级数据隔离，如需隔离再立项。

### v2.0 边界修订（2026-10-21 · 个人云公网化，用户拍板）

原红线 3"真实持仓与流水不出本机/局域网"修订为：

> **真实数据存放于本人控制的个人云资源（个人阿里云账号）内，经备案域名 + HTTPS
> 供本人微信小程序在外网使用；数据不交给任何第三方 SaaS。**

- **触发**：用户在外网（蜂窝网络）使用小程序的真实需求；个人工商注册提供小程序
  上架主体资格。
- **保持不变**：红线 1（不自动下单）、红线 4（LLM 不预测涨跌）。
- **上公网硬前提**（已执行/待办）：
  - [x] JWT 密钥轮换——旧 dev 默认密钥曾随公开仓历史泄露，已全部淘汰（star 五容器
    + invest 双进程，2026-10-21）；密钥长度保持 [32,48) 字节（≥48 会切 HS384）。
  - [x] 数据层接入 star 同款 MySQL（双后端，SQLite 保留开发/测试）。
  - [ ] 备案域名 + HTTPS + 小程序 request 合法域名。
  - [ ] 云端部署（阿里云节点容器化）+ 公网暴露面复查（限流/强制 HTTPS）+ 完整安全审计。
- **架构总览见 [07-architecture.md](../tech/architecture.md)。**

### v2.1 边界修订（2026-10-21 · 分阶段开放预埋，用户拍板）

红线 2 由"不公开注册，仅本人/家庭使用"修订为——**分阶段开放**（路线详见
[product.md §6](product.md)）：

- **O1 白名单邀请**（≤20 人亲友）：准入前提是**用户数据 owner 级隔离改造**完成——
  当前单用户数据全局共享的现状不允许直接放人进来（v1.1"如需隔离再立项"至此立项）。
- **O2 公开发布**：个体工商户/企业主体上架 + 用户协议/隐私政策/免责声明 +
  账号注销与数据导出（个保法）+ ICP 备案。
- **开放后仍永久成立的底线**：不自动下单（红线 1）、LLM 不预测涨跌（红线 4）、
  不做投资咨询/荐股（监管资质红线，负面清单见 product.md §5）、用户自身数据的
  导出与注销能力永久免费（数据主权承诺）。
- **开放带来的新责任**：运营者对用户数据承担保护义务（备份、最小访问、泄露响应），
  相关运维义务在 O2 准入清单中逐项落地。

## 四、当前标的与策略定位

| 标的 | 账户 | 风格 | 策略重点 |
|------|------|------|----------|
| 消费50ETF | A股证券账户 | 大盘质量成长，白酒权重高，高波动顺周期 | **择时与仓位**：估值分位定投 / 网格 / 趋势止损（见规则书） |
| 中证红利基金 | 个人养老金账户 | 深度价值，低波动有股息垫 | **配置与纪律**：缴存节奏 / 再平衡 / 分红方式 |

两标的风格相关性不高，构成"成长/价值"杠铃；平台原则上**分线管理、合并看风险**。

## 五、账户要点备忘

- **个人养老金账户**：缴存抵扣个税（上限 12000 元/年），领取时缴 3%；边际税率 ≥10% 即明显划算；
  资金锁定至退休，账户内可更换基金——所以策略核心是"缴满、拿住、少折腾"。
- **A股账户（场内ETF）**：T+1 交易，卖出盈利正常计税。
