# S08 · 首次使用引导（Spec）

> 优先级 P2 · 状态：**已实现（验收记录待补）**
> 原则：新用户 30 秒内完成首次核心操作，不靠文档。

## Problem

新用户打开小程序后看到示例数据的总览页——不知道：
1. 需要先配置服务器地址才能连后端
2. 示例数据不是自己的
3. 应该先"记一笔"录入真实持仓

## User Stories

- **US-1**：作为新用户，我第一次打开小程序，系统引导我配置服务器地址
- **US-2**：作为新用户，我看到"当前是示例数据"的明确提示
- **US-3**：作为新用户，我 30 秒内完成"记第一笔投资"操作

## Acceptance Criteria

### AC-1 首次启动检测

- **GIVEN** 用户首次打开小程序（storage 无 invest_server）
- **WHEN** 加载完成
- **THEN** 自动弹出"欢迎使用"引导页（3 步卡片）
- **AND** 引导页可跳过（"稍后配置"按钮）

### AC-2 三步引导

```
Step 1: 配置服务器（扫二维码或手动输入地址）
Step 2: 登录（gateway 模式自动 / direct 模式输令牌）
Step 3: 记第一笔（跳转到记一笔弹层）
```

- **GIVEN** 引导页 Step 1
- **WHEN** 用户完成配置并点击"下一步"
- **THEN** 进入 Step 2（配置已保存）
- **AND** 可随时点"跳过"结束引导

### AC-3 示例数据提示

- **GIVEN** 后端返回 `config_source: "portfolio.example.yaml"`
- **WHEN** 总览页渲染
- **THEN** 页面顶部显示黄色横幅"当前展示示例数据"
- **AND** 点击横幅跳转到"标的管理"页引导录入真实标的

### AC-4 空数据引导

- **GIVEN** 用户已配置服务器但无任何交易记录
- **WHEN** 打开流水页
- **THEN** 显示空态引导"记第一笔投资"
- **AND** 点击按钮直接弹出记一笔表单

## Out of Scope

- 多语言引导（中英切换）
- 视频教程
- 强制引导（阻断使用直到完成）

## 实现要点

1. `storage.get('invest_onboarded')` 判断是否首次
2. 引导页用 swiper 组件（3 步可滑动切换）
3. 示例数据检测：overview API 已返回 `is_example` 字段
4. 空态引导复用 S06 的 EmptyState 组件
